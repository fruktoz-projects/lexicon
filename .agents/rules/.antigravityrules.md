# Antigravity Rules - Gemini Execution Constraints

## Code Generation & Modification Rules
- NEVER use placeholders or ellipses like `// ... rest of the code remains the same` or `/* keep existing logic */`. Always provide exact, complete code blocks or unified diffs.
- DO NOT duplicate existing variables, imports, or functions. If an import or handler already exists, edit it in place.
- Keep structural edits minimal. Only modify the exact functions requested; do not reformat or overwrite unrelated files.

## Verification & Execution Gates
- After every file modification, run the project check via terminal (`npm run dev:web` / linter / `tsc --noEmit`).
- Do not mark the task complete if there are duplicated declarations or TypeScript/syntax errors in the output.
